# GameHub 实施任务清单

日期：2026-11-10。依据文档 01—24。状态记录对应当前代码和本机验证；模拟服务、官方可信规则及本机恢复不等于真实 AI、用户代码强沙箱或生产验收。

状态定义：**完成**＝本轮受控内测范围已有可用实现；**部分完成**＝有明确实现但尚有工程缺口；**外部条件阻塞**＝需要实际服务、环境或产品规则后继续；**未验收**＝没有足够测试证据。原文档 22 的候选增强功能未自动纳入。

## 分工、依赖与结果

主 agent 负责共享契约、服务集成、页面、SDK、浏览器验证、任务追踪和交付。三个并行 agent 分别负责：

- `identity_community`：账号与权限、社区反馈、官方权威房间、连接与性能测量。
- `catalog_versions`：目录、包检查、私有资源、版本审核、草稿、存档、配额回收、作者资料。
- `wallet_tasks`：任务与账本、模拟 AI/支付、成本预算、质量补偿、备份重置、数据库运行角色。

身份与准入为所有模块前置；版本产物为任务交付、审核和固定版本房间的前置；强隔离节点为任意构建、UGC 多人和真实产物自动执行的前置。共用文件由主 agent 集成，迁移编号协调后固定，不覆盖已应用历史。

## T04：游戏运行、SDK 与联机

- **T04.1 完成浏览器边界**：不同站点资源、opaque sandbox iframe、有限 MessageChannel 能力、大小/频率/nonce 校验，页面导航和授权撤销后关闭端口；子页面没有账号凭据。
- **T04.2 外部条件阻塞**：本机 Docker runtimes 无 `runsc`，WSL 仅有 docker-desktop；未把普通容器或 worker thread 当强隔离沙箱。需要独立 Linux 执行节点完成资源/网络限制、攻击样例、清理和逃逸验收。
- **T04.3 完成**：固定版本运行授权，账号会话撤销传播，云档 revision/100 KiB/结构隔离，旧结构保留，游客本机档与明确导入；已有云档不被游客导入覆盖，重置需要确认与预期 revision。
- **T04.4 完成官方单实例路径**：服务器权威官方规则、游客成员、30 秒单次连接票据、固定版本、动作幂等、私密投影、HTTP 动作与 WS 推送。
- **T04.5 完成持久化恢复，部分横向能力**：PostgreSQL 快照、sequence/lease epoch fencing、重连期限、停服后接管；同房间广播批量验证授权。多实例主持转发与跨实例主动广播尚未实现，当前应使用单实例，错误主持返回 503。普通连接粘性不能确保同房间所有玩家到达同一主持实例。
- **T04.6 完成官方与静态单人样例；UGC 多人阻塞**：原 93 项规则回归、12 款官方新房间启动/投影及服务重启恢复；独立静态计数器包无需改注册表即可发布。独立上传多人样例依赖 T04.2，当前明确拒绝。
- **验收证据**：`tests/api/rooms.test.ts`、`tests/*.test.ts`、`scripts/platform-browser.mjs`。ROOM-06、PKG-03/06 的任意不可信执行验收仍未通过，不能扩大开放范围。

## 暂时不能做及需要的配合

1. **不可信构建和多人用户游戏**：提供独立 Linux 执行节点（可安装/配置 gVisor runsc）、出网策略和资源额度。之后实现执行适配与攻击样例验收，当前仅官方可信规则和静态单人包可运行。
2. **真实 AI**：选定模型供应商，提供安全的凭据配置位置、日/月预算及创建/修改样本与成功标准。还需真实适配器、强隔离构建/浏览器检查，不能把 mock 换名上线。
3. **真实短信**：提供供应商账号、审核通过的签名模板、测试号码及预算；完成发送/回执/失败补偿联调。
4. **真实支付**：提供商户主体、渠道凭据、回调 HTTPS 域名；确认价格、有效期和已消费权益的退款规则，再做微信/支付宝完整测试。
5. **注销/找回/最终清理**：确认身份核验、账号/作品转移、账务与争议证据留存期限及人工处理责任。当前请求/支持入口可用，实际销毁保持关闭。
6. **正式部署与运维**：提供控制面和独立资源站点域名、服务器/数据库/对象存储、网关拓扑、监控联系人及备份地点；进行真实设备/网络和生产规模恢复验收。

仍需后续工程的部分单独列明：强沙箱执行适配、真实提供方与支付通道、自动产物质量流水线、房间多实例主持转发/广播、分布式对象存储与跨存储一致备份、生产监控告警集成。这些不是已经完成后只等“填密钥”；外部输入到位后仍需实现与验收。历史版本全面物理回收及注销执行依保留规则实施。
