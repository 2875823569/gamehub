# 内测范围与阶段切换

版本：1.1，设计基线。用户明确当前仅内测，并决定暂不调整游客免账号游玩。本文是当前阶段规则；原有公开版设计继续保留。

## 一、三类环境，两个发布范围

开发环境用于自动化测试、合成数据和故障注入；内测环境用于受邀人员体验实际业务；公开生产环境尚未放行。每类环境使用独立的身份、数据库、对象空间、队列、回调配置和密钥。

部署模式由服务端可信配置决定，`internal` 和 `public` 不能由 URL 参数、浏览器请求或普通运营账号切换。发布记录分别标记 `internal_catalog` 和 `public_catalog`，两者的版本指针、目录查询和运行授权分别生效。

“上架”在内测中表示进入受控测试目录，不表示公开发布。作者预览是独立的短期预览能力，不等同于任何目录发布。接口只接受当前环境允许的范围，不能提交一个自选 scope 绕过限制。

## 二、访问及游客身份

默认通过私有网络或访问网关控制测试入口；必要时由管理员生成有期限、可撤销、限制兑换次数的测试邀请。邀请兑换后颁发只限当前环境的访问会话，退出或撤销立即终止其能力。单靠 `noindex`、隐藏链接或一个长期公共口令不作为访问控制。

首次兑换邀请使用单独的引导接口，不要求用户已经持有测试会话；该接口仅校验邀请与限流并创建访问资格，不直接授予站内账号权限。其他业务接口随后校验有效测试会话。

进入测试范围后，玩家可输入昵称并以游客身份玩内测目录中的游戏，无需创建站内账号。测试访问凭证不等于站内账号，不赋予创作、点数、评论、点赞或后台权限。

创作、上传、社区互动继续使用站内注册用户。测试邀请不得授予后台角色；房间邀请只授予加入某个房间的资格，不能代替测试环境访问资格。两类凭证须分别校验，退出测试范围后旧房间链接也不能重新获得访问。

游客身份使用随机会话标识，不能通过昵称找回或合并；换浏览器或清理数据后无法保证恢复。成人用户定位保留，测试组织者限制参与对象；不把年龄自报当作已经完成正式核验。

## 三、内测发布与撤销

内测目录仍需自动检查及人工审核，保留作者主动下架、平台强制下架和版本切换语义。不能因为是内测而直接在主站执行未检查的上传代码。

内测发布校验当前环境、访问范围、账号权限、版本检查与内部审核、游戏限制及资源预算；公开资格记录可以保留待核实，但不得伪造为有效。公开环境必须另行校验文档 16 的资格及身份要求。

预览授权绑定作者、游戏、版本、环境和到期时间。初始仅作者及授权审核员可使用；邀请其他测试者体验未上架草稿是文档 22 的增强候选，未实现前不能用泄露预览 URL 替代。

内测验收重点：未经邀请无法访问测试目录或资源；游客可以游玩；普通用户不能越权；强制下架会撤销现有运行授权；链接转发不能获得更高权限。

## 四、点数与支付

内测余额为明确标识的测试点数，来自测试活动或管理员发放；不承诺兑换、退款或迁移为生产付费权益。冻结、结算、释放及退点沿用正式算法，以验证一致性。

真实微信与支付宝收款默认关闭。开发使用模拟支付提供方测试回调、重复通知和失败恢复；如所选渠道有可用的官方测试能力，则在实际开通后使用，不假定两渠道都有同等沙箱。

模拟回调只存在于开发/测试适配器并要求内部身份，公共渠道回调处理器不接收“测试成功”参数来绕过验签。测试 API、密钥和订单前缀在公开部署中必须不可用。

真实 AI 和短信可能产生外部费用。即使使用免费测试点数，也要限制账号、环境和日/月真实成本；先配置额度再开启真实调用。未配置时只运行模拟供应商，不能通过发放无限测试点数形成无限真实支出。

短信认证在内测可使用明确区分的测试提供方及受邀号码白名单；任何固定验证码或调试入口不得随公开构建发布，真实渠道需按其能力验收。

## 五、最低内测闭环

内测首先验证：获准进入测试范围 → 游客体验官方游戏 → 注册成为创作者 → 上传或 AI 创建 → 预览 → 审核进入内测目录 → 被其他受邀玩家游玩 → 提交问题 → 修复和重新验证。

最小闭环不要求先完成真实收款、正式实名、复杂推荐、公开增长或全部财务运营页面；相应接口与数据模型保留，测试适配器支持必要验证。

反馈必须能关联准确的环境、游戏版本、任务或房间及客户端版本；用户可补充期望与实际表现。修复后关联新版本并返回反馈提交人，不只在聊天中说“已处理”。

初始缺陷等级：阻断（无法使用、越权、数据破坏或账本不一致）、严重（核心流程失败）、一般（局部体验）、建议。内测邀请前应关闭已知越权、用户代码隔离和真实成本失控问题；阶段结束不允许遗留核心流程阻断。

## 六、数据清理与转正式

重置测试数据必须先显示环境、目标范围和影响，生成需要保留的报告或导出后再执行。重置停止新任务、结束会话、处理冻结点数并撤销旧邀请，避免重置后旧执行器继续写入。

测试版本可作为作者确认的迁移候选，但不自动复制测试账号权限、余额、订单、手机号验证或审核资格。公开发布前重新核查文件摘要、权限、素材、公开资格及目标 SDK。

正式账号需完成最终确定的注册及身份流程，测试点数与订单不进入生产账本。需要迁移的源码、作品归属及反馈须有明确清单和授权，不复制整个内测数据库作为生产初始数据。

公开启用是独立的发布动作，需要用户决定及文档 16 条件完成。不是把环境变量从 `internal` 改成 `public` 就自然取得上线资格。当前不重复询问该阶段决定。

## 七、内测验收标识

INT-01 访问邀请可过期、撤销、限次，凭证不跨环境；INT-02 游客可在测试范围游玩但不能创作和互动；INT-03 内测目录与公开资格校验互不冒充；INT-04 模拟支付不能打到生产或入真实账；INT-05 测试点数仍受真实模型成本上限约束；INT-06 数据重置后旧任务和票据失效；INT-07 问题可定位到具体版本并闭环复测。
