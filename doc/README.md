## 项目定位

在现有 GameHub / 玩伴 PLAYROOM 上升级网页游戏平台，保留 12 款官方游戏。面向中国大陆成年用户，支持 AI 创作与修改、文件上传、单人与多人游戏、版本审核、账号、点数充值和社区互动。

当前内测保留游客免账号游玩，创作等能力使用手机号账号；真实收款默认关闭，使用测试点数验证收费逻辑。未来公开版保留微信支付与支付宝设计。分阶段交付，暂无固定工期或费用承诺。

## 当前阶段与后续事项

用户已明确现阶段不调整游客模式。内测按 [文档 20](./20-内测范围与阶段切换.md) 管理访问、发布范围、测试点数及数据；实名调整留到公开上线前处理，本轮不再追问。官方依据保留于 [文档 16](./16-上线条件与官方依据.md)，不把“内测”名称写成自动豁免结论。

公开游戏还需满足经核实的出版及运营适用条件，平台自动检查和人工审核不能代替外部准入。文档已设计独立公开资格门槛，未满足时不能放行公开服务。

## 阅读约定

- **已提出**：用户明确要求，具体业务细则可能尚未确定。
- **建议**：用于讨论的推荐方案，未经确认不能当作已定需求。
- **待确认**：会影响范围、成本、体验或技术实现的产品决策。
- **现状**：从现有项目文件获得的事实，不代表新平台必须沿用。
- **授权制定**：用户授权代理决定的常规规则，作为当前设计基线，可后续调整，不代表用户逐条确认。

具体配置数值属于初始设计值，需通过验证后确定生产配置。实际运营主体、供应商、定价、正式商户和资格证明属于实施与上线输入，文档已给出核实路径，不能伪造为已经取得。
