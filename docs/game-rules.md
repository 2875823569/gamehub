# 吹牛骰子：已确认的第一版规则

1. 2～6 人，免注册，通过昵称、房间码或邀请链接加入。
2. 房主开始游戏；所有在座玩家需在线。中途加入的人等下一局，不拿本局骰子。
3. 每人固定 5 颗骰子，每局重新摇骰，只有自己能看到自己的骰子。
4. 1 点是万能点，计入任意 2～6 点；只允许叫 2～6 点，不使用“叫斋”。
5. 服务端随机选择首位玩家，之后按入座顺序轮流操作。
6. 叫点表示全场至少有多少颗某点数的骰子（包含万能 1 点）。
7. 必须增加数量，或保持数量并增加点数。叫数范围为 1 到全场总骰数。
8. 轮到自己时可叫点，或质疑上一家并开骰；第一手没有上一家，只能叫点。
9. 开骰后，如果符合点数的骰子数量达到叫数，开骰者输；数量不足则上一位叫点者输。
10. **出现一个输家，整局立即结束。没有减骰、淘汰或多轮存活赛制。**
11. 结算显示全场骰子、最后叫点和准确计数。房主可以发起全新一局。
12. 正常回合不倒计时。掉线保留 60 秒；期限内重连恢复同一手骰子，超时判定离线玩家弃权为输家并结束本局。
13. 对局参与者主动离开立即判负。若多位玩家掉线，先到期者导致本局结束，之后到期者不改变结果。
14. 房主离开或掉线到期后，房主移交给剩余在线玩家，或剩余的首位玩家。
15. 所有人离开或掉线到期后清理房间。未参加本局的后来玩家离开，不影响当前对局。
