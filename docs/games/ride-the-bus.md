# 搭巴士

## 来源与玩法定位

参考 [PsyCat Games 的 Ride the Bus 规则](https://psycatgames.com/magazine/party-games/ride-the-bus/)（资料读取日期：2026-11-09）。采用四轮猜牌、金字塔配牌、剩牌最多者搭巴士的三阶段结构；本站是适合手机实时联机的积分改编，不规定饮酒量。

适合2～8人。每个阶段使用服务器新洗好的独立52张牌堆，不含大小王。同一阶段无放回抽牌；这样8人局也不会出现手牌、金字塔和巴士合用一副牌导致牌数不足的问题。点数从2至A，A最大；花色为红桃、方块、黑桃、梅花。

## 第一阶段：四轮猜牌

按座位顺序依次猜牌，每个人完成当前轮后才进入下一轮。每次选择后发一张牌，猜对得1分，猜错或超时得0分；无论对错，都保留发到的牌。

1. 红或黑：红桃、方块为红，黑桃、梅花为黑。
2. 高或低：与自己的第一张牌比较，点数相等时两种选择都不算猜对。
3. 区间内或外：以自己的前两张牌为边界；“内”是严格大于小点数且小于大点数，“外”是严格低于小点数或高于大点数。等于任一边界均不算猜对；前两张相等时，“内”没有合法命中值。
4. 花色：猜四种花色之一。

每次操作限时30秒，超时自动发牌并记为猜错。每个人最终拥有4张手牌，只有本人能看到点数和花色；其他玩家和观战者只能看到手牌数量及积分。猜牌结果日志不公开手牌内容。

## 第二阶段：金字塔

服务器从独立牌堆生成15张牌，按底部5张、4张、3张、2张、顶部1张的顺序逐张公开，五层分别值1～5分。

每翻一张牌，所有参赛者同时选择一次：打出自己全部与公开牌点数相同的手牌，或保留手牌。每打出一张得当前层数对应的积分。没有同点数手牌时只能保留。为简化手机操作，本站不提供只打出部分同点数牌的选项；这是明确的本站改编。

每张公开牌停留最多25秒；全员提交后立即翻下一张，超时未提交者自动保留。玩家可见已提交人数及自己的选择，不能看到未打出的他人手牌。已提交本张牌的人不得重复操作。

## 第三阶段：搭巴士

金字塔15张处理完后，剩余手牌最多者搭巴士；并列时比较剩余手牌的最大点数，仍相同时按本局座位先后决定。若全员清空手牌，则也按座位先后选出巴士挑战者。房主及所有其他玩家不能代替挑战者操作。

挑战者使用独立牌堆，依次完成红黑、高低、区间内外、花色四次猜测，判定与第一阶段相同。每次最多30秒，猜对得1分。巴士挑战牌公开显示，原有手牌仍只对本人可见。

无论答对答错，固定四次后结束，不存在答错重来或无限循环。结果展示挑战者答对次数和所有人的总积分，积分最高者为本场积分领先者；平分并列。

## 联机与异常

- 服务器保管牌堆、未公开金字塔及全部私人手牌，只发送适合当前观看者的界面数据。
- 所有动作校验参赛资格、当前阶段、回合、动作值及截止时间；观战者没有游戏操作。
- 对局加入、退出、掉线宽限、房主移交和重开遵守[公共规则](README.md)。倒计时不会因为断线暂停。
- 服务器处理超时后必定推进回合或结束，避免房间卡住。房主可在结束后创建下一局。
