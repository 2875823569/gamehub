# 我从来没有

## 来源与传统核心

- [PsyCat Games — Never Have I Ever](https://psycatgames.com/app/never-have-i-ever/)（2026-11-09 阅读）：向全体读出一条“我从来没有……”经历，做过的人回应；不饮酒版本可用手指数记录经历。
- [加州大学 4-H 活动资料](https://cetrinity.ucanr.edu/files/107599.pdf)为调查时找到的辅助资料，本次读取遇到站点迁移，未作为唯一规则依据。

本站使用原创中文日常经历题库，不复制来源题目。保留共同回答同一经历、揭晓后交流故事的核心，改编为固定轮数、私密提交及经历计数。经历多寡不代表胜负，不设饮酒要求。

## 本站规则

1. 3～10名玩家参加。房主开局后，服务器从至少30条题目中随机抽取不重复的8题。
2. 每题有45秒作答时间。每名玩家可选择“做过”“没做过”或“跳过”；选择提交后不能修改或再次提交。
3. 收齐全员选择或45秒到期后统一揭晓。超时未提交按“跳过”处理，任何人都可主动跳过，不扣分。
4. 作答阶段每个人只能看见自己的选择，其他人只显示“已提交/等待回答”。不能看见别人的具体答案；旁观者只能看进度。
5. 揭晓时展示每个人本题的选择与累计经历数。“做过”使自己的经历数加1，其余选择不增加；跳过另行统计，不误算为没做过。
6. 每题揭晓保持10秒供交流，房主也可点击“下一题”提前推进。第8题揭晓时即结束，显示全员经历数和跳过次数，不评定优劣。
7. 固定参赛名单中的玩家才可回答；后来加入者只能观战。房主才可提前推进揭晓。
8. 刷新重连、断线60秒、主动退出、房主移交和重开采用[公共联机规则](README.md)。题目倒计时不会因断线暂停。游戏结束后房主可重新开局，重新抽题。

## 时间与结果

正常一局约3～7分钟。若全员无人操作，服务器仍会逐题按超时跳过并结束，不会无限等待。答题期限后的迟到答案不接受；揭晓时答案与计数只结算一次。
