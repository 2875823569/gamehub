# 你宁愿选哪个

规则核对日期：2026-11-09。适用人数3～10人，每人使用自己的设备实时联机。

## 来源与传统核心

- [PsyCat Games：Would you rather](https://psycatgames.com/app/would-you-rather/)：每题提供两个选择，全员同时表态并比较阵营；其酒桌变体按多数、少数、平票区分结果。
- [Pass and Play Games：Would You Rather rules](https://passandplaygames.com/guides/would-you-rather)：介绍秘密投票、集中揭晓和跳过。传统版本可以不计分，也没有统一官方规则。

本站保留“同一道二选一、独立选择、一起揭晓”的核心，将其改编成下述固定轮数的默契积分游戏。题库为本站原创中文内容，不复制来源题目；不规定饮酒量。

## 本站规则

1. 房主开始时，服务器洗牌，从至少30道题中抽取8道不同题目。每轮所有参赛者看到相同的A、B两个选项。
2. 每人有45秒秘密选择A、B或跳过；每题只能提交一次，不能修改。未提交者在期限到达时自动记为跳过。
3. 在全员作答或期限到达前，只向本人显示自己的选择。不会展示其他人的答案、投票数量、阵营比例或实时分数变化；其他人统一显示“答案未揭晓”。
4. 揭晓时展示每人的阵营、A/B人数和本轮得分。A、B的计数不包括跳过者。
5. 人数较多的阵营，每位有效作答者得1分；少数派得0分。A、B人数相等时全员得0分；所有有效作答者同选一项时，这些作答者各得1分。全员跳过时无人得分。跳过不扣分也不得分。
6. 前7轮揭晓持续10秒，然后服务器自动进入下一题；房主可点击“下一题”提前继续。投票尚未揭晓时，房主也不能提前翻题。
7. 第8轮揭晓后立即结束，显示所有人的最终积分及最高分玩家；同分并列获胜。全员0分时显示“本局暂无积分赢家”。房主可重新开局。

## 联机边界

开始后参赛名单固定；后来加入者仅观战，下局参加。观战者能看到题目和已公开结果，不能投票或推进题目。断线60秒内可以恢复；45秒作答期限继续运行。参与者离开或断线超过60秒则由公共房间服务中止整局，其他人可重新开局；观战者离开不影响游戏。参见[公共联机规则](README.md)。

## 实现约定

私有服务器状态保存题序、未揭晓答案和分数；客户端只得到按观察者裁剪后的展示内容。输入仅接受`vote`动作的`A`、`B`、`skip`，以及揭晓阶段由房主提交的`next`。服务器拒绝重复、迟到、越权和未知动作；所有阶段期限都由服务器推进。
