# 数字炸弹

## 来源与传统核心

查阅日期：2026-11-09。

- [数字炸弹在线产品及玩法](https://numberbomb.com/index.php?lang=zh)：服务器随机选择隐藏数字，玩家轮流选数、缩小范围，命中者失败；产品含多炸弹及倒计时等变体。
- [《推理学院》数字炸弹玩法说明](https://www.gameres.com/forum/t/903617)：随机选数、参与者分别报数、系统缩减范围，直到某位玩家命中。

本站采用单炸弹的传统核心。人数、30秒回合、闭区间表示、轮换首位及晚加入观战是本站固定的联机规则，不照搬上述产品的所有变体。

## 本站完整规则

1. 2～10人开局。房主开始后固定本局参赛名单，服务器在1～100（包括1和100）均匀生成一个秘密整数，所有玩家都不知道答案。
2. 第一局按入座顺序开始；第N局首位为名单中第`(N-1) mod 人数`位，之后按入座顺序轮流猜数。换局重新生成炸弹。
3. 界面始终展示**可选择整数的闭区间**，两端都能选。例如初始1～100，猜50且炸弹更大，则下一范围是51～100；若炸弹更小则为1～49。已猜过的安全数字不会再次出现。
4. 当前玩家提交范围内的一个整数。猜中炸弹则立即结束本局，该玩家失败，其他参赛者避开炸弹；所有人看到炸弹答案及猜数记录。
5. 未猜中则缩小范围，下一位获得新的30秒。范围可能缩小到只有一个整数，此时该数仍是唯一合法选择，不另行随机改变炸弹。
6. 每回合限30秒，以服务器时间为准。时间到仍未提交，当前玩家超时失败、全局结束并揭晓答案。不会自动替玩家猜数，也不会让浏览器决定是否超时。
7. 拒绝小数、非有限值、字符串、超出当前区间的数字，以及非当前玩家或观战者操作；无效操作不改变范围和截止时间。
8. 房主可以在结束后再次开局。晚加入者仅观战。断线重连、退出与房主移交遵循[公共联机规则](README.md)；回合计时不会因为断线暂停，30秒超时可能先于60秒断线清理发生。
9. 本游戏仅展示胜负，不规定饮酒量或饮酒任务。

## 信息边界与验收

未结束前，浏览器只收到合法区间、当前玩家、截止时间、已公开猜数记录和本人可用输入框；秘密整数不在公开状态中。即使区间仅余一个数字，仍只发送公开区间，结束后才明确标记炸弹。测试应覆盖1/100端点、单值区间、秘密信息、非法输入、错误回合、超时与重开首位轮换。
