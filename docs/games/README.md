# 游戏规则目录

大厅目前只有两个分类：“行酒令”包含原有吹牛骰子及以下十款聚会游戏；“其他”包含[默契拆弹](defuse.md)，支持1人独立解谜或2～6人合作拆弹。

## 行酒令

本次新增国王杯、我从来没有、真心话大冒险、谁最可能、你宁愿选哪个、搭巴士、数字炸弹、逢七过、分类接龙、别数到31。保留现有吹牛骰子。

选取依据为多个聚会游戏规则网站、现有在线产品和大学活动资料中反复出现的成熟玩法，以及手机联机的适配程度；这是热门精选，不宣称是有统一统计依据的热度前十排名。各子文档列明来源、传统核心和本站改编，须先写文档再实现对应游戏。

## 公共联机规则

- 全中文、免注册。房主选择游戏创建房间，其他玩家通过房间码或链接使用各自设备加入。
- 房间游戏固定，换游戏请回到大厅创建新房间。各游戏人数范围见对应文档。
- 房主开始及重新开局；全员在线且达到最低人数才能开始。
- 对局开始后固定参赛名单。后来加入者观战，下一局再参与。
- 所有随机数、牌堆、秘密答案、回合、计分及期限由服务器决定。投票收齐之前仅本人可见自己的选择，绝不将服务器私有状态直接发送到浏览器。
- 断线身份保留60秒，刷新同一标签页可恢复。带回合倒计时的游戏不会因断线暂停；期限先到则按游戏规则处理。
- 参赛者主动退出或断线满60秒仍未回来，当前对局结束并显示中止原因；其他人可重新开局。观战者离开不影响对局。房主离开后自动移交房主。
- 空房自动清理；昵称和房间内容按文本呈现。没有账号系统、长期排行榜或跨设备身份恢复。
- 游戏通过积分、胜负和互动任务进行；任务允许跳过，不规定饮酒量。

## 开发分工

每款游戏由独立 agent 负责自己的规则文档、服务端游戏模块、前端元数据和规则测试。公共协议、房间服务、共用界面、集成测试及部署由主 agent 整合。并发上限内分批执行，避免同时修改公共文件。
