# 分类接龙

## 来源与本站版本

2026-11-09 查阅：

- [Drinking Game Commission 的 Categories 规则](https://drinkinggamecommission.com/rules/categories)：三人以上，按顺序说出同类事物，不得重复；未及时回答或答非所问会失败。该站自称趣味规则站，并非真实体育监管机构。
- [PsyCat 的 Categories 卡牌变体](https://psycatgames.com/magazine/party-games/categories-card-game/)：抽牌决定每次回答数量。本站只参考类别示例，**不采用**该抽牌规则。

本站采用每人每次一个词的中文联机接龙。把线下节拍替换为服务器倒计时；所有惩罚转换为本局胜负，不规定饮酒量。

## 人数、目标和开局

3～10人。房主开始后，有30秒从水果、动物、城市、电影、歌曲、运动、食物、职业中选一个类别；房主未选择时默认水果。第一局按入座顺序，后续每局首位向后轮换一人。全员共同完成三圈即全员通关，最多接受人数乘3个词。

## 输入和审核

1. 当前玩家有30秒输入一个1～20字的词。空白、控制字符、零宽字符及超长输入不被接受。
2. 服务器使用 Unicode NFKC 归一化，去除全部空白并转小写后比较：如 `Ａｐｐｌｅ`、`apple` 和 `a p p l e` 视为重复；重复当场判该玩家失败并结束本局。不同同义词是否算同一答案交由人工判断。
3. 新词提交后公开展示，进入15秒审核。朋友讨论是否符合类别，由房主点击“有效，继续”或“不符类别”；房主提交自己的词也要走同一审核流程。服务器只判断文本重复，不声称可以自动理解词义。
4. 审核时限内未裁定则自动接受。接受后计入有效词列表，该玩家加1分，轮到下一人；不符类别则提交者失败，本局结束。
5. 当前玩家在输入阶段可以选择“想不出来，认输”；这会直接结束本局。输入超时同样判当前玩家失败。审核中不允许重新提交、撤回或修改答案。

## 结束和展示

重复、被判不符类别、认输或输入超时产生一位输家，展示其姓名与原因、已接受词语和所有玩家贡献数。三圈全部通过则显示全员通关与贡献数，不额外排名。结束后仅房主可以重新开局。

## 联机边界

只有固定参赛名单中的玩家可以操作。选择类别及审核仅房主可操作，提交和认输仅当前玩家可操作；观战者可看公开记录，无操作按钮。非法操作不推进回合、不重置期限。所有阶段在服务器判定期限，迟到操作被拒绝。断线、刷新、加入、退出及中止规则遵循[公共规则](README.md)；倒计时不因断线暂停。
