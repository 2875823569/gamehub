# 逢七过

## 来源与传统核心

2026-11-09 核对以下规则：

- [生活社交单邦团：逢七过](https://www.sohu.com/a/525332845_121299525)：至少三人，轮流从1数起，7的倍数或包含7的数字须说“过”，说错或犹豫超时者失败。
- [Drinking Games：Buzz](https://www.drinkinggames.co.uk/buzz-drinking-game.php)：同样采用依次报数与替代词，但额外包含11、22等重复双位数变体。本站不采用这条额外规则。

## 本站固定版本

支持3～10人，每人使用自己的设备加入同一房间。房主开始；第一局按入座顺序从第一位开始，之后每局起始座位顺移一位，以局号决定。每局都从1开始。

当前玩家在8秒内点击“报数”或“过”。“报数”按钮自动报出当前数字，不用重复键入。只有以下两种数字须选择“过”：

1. 是7的倍数，例如7、14、21、49。
2. 十进制写法包含7，例如17、27、70、77。

两条满足其一即可。因此11、22、33等不含7且不是7倍数的数字正常报数；不使用数字和、逆转方向或其他附加变体。界面显示当前数字和两个同等可选按钮，提交前不提示正确选项。

选对后数字加一，并轮到下一个座位。选错则当前玩家成为本局输家，立即结束。倒计时到达时仍未有效提交也判当前玩家失败；不会自动代选。非法接口动作（错误玩家、错误动作类型、携带不支持的值）被拒绝，不当成一局中的“答错”。

所有人连续完成1～100即全员通关，避免无限对局。结束时展示失败原因或共同通关结果、每人正确次数与最近20步记录。结束后房主可重开。

## 联机与时间

服务器掌握当前数字、行动玩家和8秒期限，以服务器收到消息的时刻判定是否及时。刷新不重新计时。观战者看见公开进度但不能操作。退出、掉线、房主移交和重连遵循[公共联机规则](README.md)；8秒行动期限优先于60秒断线宽限。

本站将线下常见3秒放宽到8秒，并使用“局号轮换先手、固定从1开始、100通关”的网页改编。不规定饮酒量或强制惩罚。

## 验收要点

7、17、49、70、77必须过；普通11不能过；非当前玩家不能操作；错误选择和到期均结束且清除期限；终局无操作按钮；旁观者不能获取行动按钮；100之后不进入101；重复提交及不支持的动作不能修改状态。
