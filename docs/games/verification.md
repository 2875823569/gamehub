## 交付范围

新增十个游戏模块、十份有来源的规则文档、十份前端元数据，以及大厅和共享手机对局界面。十款游戏分别由十个独立 agent 实现，每款先写规则文档再写代码。主 agent 完成服务器整合、协议、共享 UI、联机测试与发布验证。

公共接口为 `packages/games/core.ts`，服务器注册表为 `packages/games/registry.ts`。每个模块支持初始化、合法操作、针对玩家的公开视图和超时推进。游戏随机数与私有状态均在服务器中；客户端只接收 `GameDisplay`，不接收原始游戏状态。

游戏操作按请求ID逐条确认；其他玩家产生的状态广播不会误解除本人的提交等待状态。非法动作在状态副本上验证，拒绝时不污染对局。房间版本用于验证多位玩家收到了同一操作的广播。现有不带请求ID的吹牛骰子客户端仍兼容。
