# 默契拆弹

本站原创的合作解谜小游戏，归入“其他”，支持1～6人。一人可以直接开局；多人共同胜负，没有个人淘汰。

## 目标与操作

整局共180秒，依次解决三个模块：六色线路、三位密码、四个符号的排列。三个模块共享三次失误机会。全部解开则成功；第三次失误或时间用尽则失败。误操作不重置倒计时。

- 六色线路：按从左到右的编号显示六根不同颜色的线。结合排除线索，点击唯一安全的线路。
- 三位密码：三个数字都在1～9内且互不重复。通过两两之和、总和和大小关系推算密码，输入三位数字。
- 符号排序：四个符号编号固定为1～4，结合前后关系确定顺序，输入四位编号，每个编号恰好使用一次。

每个模块有六条线索。单人获得全部线索；多人按入座顺序均分，最多六人，每人至少一条。可以当面交流或使用自己的语音工具沟通；游戏内不提供语音。任何参赛者都可以提交，答对后立即切换模块。多人同时提交时，服务器按顺序处理；旧模块的提交不影响新模块。格式无效不会扣失误，格式正确但答案错误会扣一次。

## 房间与结果

房主开始与重开，所有人在线即可开始；晚加入者观战，不获得私有线索或操作按钮。刷新可恢复原身份和线索，倒计时继续。参赛者退出或掉线超过60秒按平台规则中止本局。结算显示成功／失败、耗时、已完成模块及每个模块的答案，支持重新随机开局。

所有答案、计时和判定由服务器持有。浏览器仅接收公共模块信息、自己的线索和操作记录，不接收完整游戏状态。
