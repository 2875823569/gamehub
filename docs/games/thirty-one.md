# 别数到31

## 来源与传统核心

于2026年11月9日核实：

- [阿尔伯塔大学活动演示《Drinking Games》](https://sites.ualberta.ca/~acexc/presentations/DrinkingGames.pdf)，第2～5页介绍 Baskin & Robbins 31：按座次轮流，每人至多报三个数，说到31者失败。
- [College Beer Games 的 Baskin Robbins 31 规则](https://www.collegebeergames.com/games/baskin-robbins-31)：从1开始，每次连续报一、二或三个数，下家接续，报到31者失败。

本站保留连续计数与规避31的策略核心，不执行饮酒惩罚。本站人数、回合期限、非法输入处理及先手轮换属于联机改编；不采用原网页中的输家先手变体。

## 本站完整规则

1. 2～10位玩家，按入座顺序轮流。第一局第一位入座者先手；第N局由当前名单的第 `(N－1) mod 人数` 位先手。
2. 本局从1开始，界面显示最后一个已报数字与下一个待报数字。当前玩家点“报1个”“报2个”或“报3个”，服务器自动生成连续的数字，不能跳号。
3. 每次只能报1～3个数字，报到31的玩家立即成为本局输家，其他玩家获胜；结算展示最后报数、输家与完整历史。
4. 不允许一次操作越过31。当最后已报数为28时可报1、2、3个；为29时只可报1、2个；为30时只可报1个。报到31仍是合法操作，但会输。
5. 每回合30秒，按服务器时间计算。超时当前玩家失败，本局立即结束；不会替玩家自动选数字。期限到达之后的操作拒绝，等待服务器结算。
6. 非法操作（非整数、无穷数、越界数量、错误动作、非本人回合、观战者操作）拒绝且不修改对局。
7. 房主可在结束后再开一局，数字与历史清空。先手按局数轮换，并不强制上一局输家先手。

## 联机与隐私

本游戏所有报数均为公开信息。浏览器只收到展示内容，服务器保存权威状态。对局后加入的玩家观战，不能操作；刷新原标签页可恢复原身份。断线保留60秒但回合倒计时不中断；退出、断线清理和房主移交遵循[公共联机规则](README.md)。任何结束路径均清除回合期限。

## 验证重点

边界28/29/30与恰好31；错误输入不修改状态；非当前人和观战权限；完整对局结束；真实服务器期限处理所依赖的 timeout；重玩及先手轮换。
