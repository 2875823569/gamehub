# 本地运行与 cpolar 联机

游戏运行在这台 Windows 电脑上，通过 cpolar 免费中国区隧道分享给朋友，不需要购买云服务器。

## 日常操作

打开桌面 `GameHub` 文件夹：

1. 双击 **启动本地联机.cmd**。脚本构建网页，启动本地房间服务，再启动 cpolar；运行成功后显示 Public HTTP 和 Public HTTPS 地址。
2. 用这个公网地址打开游戏，创建房间，分享邀请链接给朋友。
3. 需要重新查看地址时，双击 **查看联机地址.cmd**。地址也保存在 `work/local-address.txt`。
4. 玩完双击 **停止本地联机.cmd**，关闭本项目的游戏服务和隧道。

关闭启动脚本的命令窗口不会停止游戏，因为服务在后台运行。停止脚本通过进程 ID 和启动时间匹配本项目进程，避免误停其他程序。没有设置开机自启或修改休眠设置；关机、休眠、断网都会使朋友无法继续访问。

免费随机地址可能在重启或服务端调整时变化。每次以启动脚本输出为准，旧的邀请链接可能失效。查看地址只反映最近分配的地址和进程状态，不代表公网一定可达。

## 当前实现

- 本地监听 `127.0.0.1:8787`，cpolar 仅转发该游戏端口。
- 使用 `wrangler dev --local` 在电脑内运行 Worker / Durable Object，房间状态保存在 `.wrangler/state`，不依赖 Cloudflare 线上房间。
- 此方式适合朋友试玩，不等于已经迁移为长期生产用的独立 Node.js 服务。不要删除运行中的 `.wrangler` 数据。
- cpolar 程序及账号配置放在 `work/cpolar/`；整个 `work/` 已被 Git 忽略，源码备份不包含密钥、客户端程序、日志或房间数据。
- 未注册 Windows 服务；未启用 cpolar 管理网页、请求检查器、SSH 或远程桌面隧道；没有购买套餐。
- 原 Cloudflare 站点仍保留，两个部署中的房间互不相通。

## 复用与排错

已有进程正常时重复启动会复用，不额外开启服务。端口被其他未登记程序占用时，脚本会报错，不会直接结束未知程序。

本地打不开：查看 `work/game-server.err.log`。公网地址没生成：查看 `work/cpolar/tunnel.out.log`、`work/cpolar/tunnel.err.log`。

若更改代码，先停止再重新启动，启动时会自动构建。换电脑需重新安装 Node.js、执行 `npm ci`，从 cpolar 官方获取客户端并配置自己的账号；不要公开分享账号配置。

HTTP 公网完整集成测试通过，包含叫点、开骰、重开、重连、晚加入、离开判负、真实 60 秒断线超时及空房间清理。HTTPS 六人程序测试通过；但浏览器 HTTPS 长连接仍出现失败，因此暂先使用 HTTP 地址试玩。HTTP 不加密，不适合承载账号密码等敏感内容。本游戏目前仅昵称入座。

没有关闭证书验证或调整浏览器安全设置。HTTPS 页面能打开不等于长连接稳定，不把一次程序测试通过视为所有客户端兼容。

本机有网络代理，尚不能据此保证不同运营商的无 VPN 体验。分享前请用手机关闭 Wi-Fi 和 VPN，以移动数据实际验证打开页面、创建/加入房间。
